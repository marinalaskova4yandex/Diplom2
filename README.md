# Stellar Burgers — Автотесты API

Репозиторий содержит автотесты для API сервиса Stellar Burgers. Тестируются только те эндпоинты и сценарии, которые указаны в техническом задании.

---

## Покрытые сценарии (по заданию)

### Создание пользователя
* **Создание уникального пользователя** (успешный кейс).
* **Попытка создания пользователя**, который уже зарегистрирован (ожидаемая ошибка).
* **Создание пользователя без заполнения** одного из обязательных полей (валидация).

### Логин пользователя
* **Вход под существующим пользователем** (успешный кейс).
* **Вход с неверным логином и паролем** (ошибка авторизации).

### Создание заказа
* **С авторизацией** (успешный кейс).
* **Без авторизации** (ошибка доступа).
* **С ингредиентами** (успешный кейс).
* **Без ингредиентов** (ошибка валидации).
* **С неверным хешем ингредиентов** (ошибка сервера/валидации).

---

## Используемые библиотеки

* **pytest** — фреймворк для построения и запуска тестов.
* **requests** — выполнение HTTP‑запросов к API Stellar Burgers.
* **allure-pytest** — интеграция с Allure для создания детальных отчетов.

## Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com
cd stellar-burgers-api-tests
```

### 2. Настройка виртуального окружения
```bash
# Для macOS / Linux
python3 -m venv venv
source venv/bin/activate

# Для Windows
python -m venv venv
source venv/Scripts/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Запуск тестов
```bash
# Обычный запуск всех тестов в консоли
pytest

# Запуск тестов сбором логов для Allure-отчета
pytest --alluredir=allure-results
```

### 5. Генерация отчетов Allure
*Для формирования красивого HTML-отчета убедитесь, что на вашей машине установлен утилитный пакет [Allure CLI](https://readme.io).*

```bash
# Локальная генерация отчета и его автоматическое открытие в браузере
allure serve allure-results
```
