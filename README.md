# Stellar Burgers — Автотесты API

Автотесты для API сервиса Stellar Burgers.  
Тестируются только те эндпоинты и сценарии, которые указаны в задании.

## Покрытые сценарии (по заданию)

### Создание пользователя
- Создание уникального пользователя (успешный кейс).
- Попытка создания пользователя, который уже зарегистрирован (ожидаемая ошибка).
- Создание пользователя без заполнения одного из обязательных полей (валидация).

### Логин пользователя
- Вход под существующим пользователем (успешный кейс).
- Вход с неверным логином и паролем (ошибка авторизации).

### Создание заказа
- С авторизацией (успешный кейс).
- Без авторизации (ошибка доступа).
- С ингредиентами.
- Без ингредиентов.
- С неверным хешем ингредиентов.

## Используемые библиотеки
- `pytest` — фреймворк для написания тестов.
- `requests` — выполнение HTTP‑запросов к API.
- `allure-pytest` — генерация подробных отчётов Allure.
